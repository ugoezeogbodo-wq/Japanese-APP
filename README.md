## 🚀 Featured Project
### 1. Jya Jya Japanese (Japanese Character Learning Application)
*An interactive desktop application designed to optimize Hiragana, Katakana, and Kanji retention through gamified exercises and custom scheduling.

[![Status](https://img.shields.io/badge/Status-Work%20in%20Progress-yellow?style=flat-square)]()

* **Custom Spaced-Repetition Algorithm:** Engineered a backend algorithm that calculates review intervals dynamically based on real-time user accuracy and error rates.
* **Interactive Mascot Helpers:** Developed event-driven character assistants with distinct personalities to deliver contextual mnemonics, real-time motivation, and personalized feedback.
* **Data Persistence & Analytics:** Implemented robust JSON file-based persistence to automatically save user preferences, streaks, and learning statistics across multiple sessions.
* **External Integration:** Utilized `jaconv` for seamless romaji-to-hiragana conversions and integrated `kradfile` JSON data to fetch kanji radical components.
* **Tech Stack:** Python, CTkinter, Pillow, JSON, jaconv, kradfile
